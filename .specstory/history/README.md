# Specstory History

This directory contains AI-assisted development history captured during the project.

The history should provide evidence of the structured development workflow:

Requirement
→ Specification
→ Plan
→ Implementation
→ Testing
→ Review
→ Fix

Prompt history should demonstrate that AI was used incrementally rather than being asked to build the entire application in one step.

## Important

Do not commit:

* passwords
* API keys
* tokens
* database credentials
* private personal information

Significant AI decisions should also be summarized in:

`docs/prompt-history.md`

The generated history is evidence of the development process and should remain reviewable as part of the final GitHub submission.
